Research

Project Trinity

Project Trinity is the AI party: the tank, healer and DPS that run with you. The goal was to make them extremely competent, like my own days chasing leaderboards and day-one clears.

I

How the party plays

The arena publishes what's happening around the party: where the boss is facing, what it's winding up, who's hurt, what's on the floor. Each hero's brain reads those facts and picks one thing to do, then sends it to the game like a player's button press would.

The AI sees what you'd see and nothing more. It has no secret view of a fight. The only thing I take away is knowledge, and only where it helps the raid leader fantasy. I just tell it less.

You lead it. The Trinity Dial sets how safe or how greedy the party plays, and your orders (focus a target, focus the adds, help a teammate) outrank it.

II

How the research is done

It's half research, half game development: a machine learning project and a game built at once.

The fights run without a picture, in the cloud, over and over, each run from a different seed. Every choice each hero makes is written down with the reason it won, so a wipe can be read back step by step.

A change to how the party plays counts only when it holds up across many runs, not one lucky pull. Then I play it, and watch it.

III

How the game is built

The building is research too. It started with one session, then it grew, and it kept growing. Now it's one orchestrator and a seat for each job, each one working off a sheet with a line it has to knock off.

I design it, play it and decide. Every change is checked, reviewed and watched before it goes in.

Deeper pieces on each of these will come as devlog posts.
